# 教学评价规则

> 文档编号：**JW-08**　｜　适用范围：全体学生、任课教师　｜　版本：**v1.1**（2026-09-22 按作者确认修订）
> 图例：**⚙** = 系统已自动校验，数值与代码一致；**【制度】** = 管理制度条文，系统当前不自动校验。
> **v1.1 修订**：① 补上"只能评价本人已选课程"的**服务端**校验；② 评价对象**由课程决定**（不采信传入的教师编号）；
> ③ **改为匿名评教**（教师看不到提交人；界面显示"匿名"）。三处此前都只有界面约束、服务端不拦。

---

## 1. 总则

1.1 教学评价是学生对任课教师教学情况的反馈，用于改进教学、作为教师教学考核的参考。**【制度】**

1.2 学生**只能**评价**本人已选课程**的授课教师；未选的课程提交评价会被服务端拒绝：
"你还没有选这门课，不能评价该课程的教师"。**⚙**（2026-09-22 补上服务端强校验，原先只有界面约束）

1.3 **评价对象由课程决定**：系统按"该课程的授课教师"记录评价，**不采信调用方传入的教师编号**。
若传入的教师与课程授课教师不一致，系统按课程纠正并记录日志。**⚙**

## 2. 评价方式

2.1 评价采用 **5 星制**：评分范围为 **1~5 的整数**（5 星为最高）。**⚙**

2.2 学生可选择填写**文字评价内容**；不填写文字内容时，只提交评分。**⚙**

2.3 评价提交时须对应到**具体的课程**与**该课程的授课教师**。**⚙**

2.4 示例：某学生对《Java 程序设计》（授课教师 10001）给出 5 星评价，并附文字评价。**⚙**

## 3. 提交与修改

3.1 **每名学生针对每门课程**只能提交**一次**评价；重复提交由系统拒绝（数据库唯一约束保证）。**⚙**

3.2 **评价一经提交不可修改、不可撤回。** **⚙**（系统未提供修改或删除评价的接口）

3.3 学生可查询自己**是否已评价**某门课程，以及已提交的评价内容。**⚙**

3.4 **【制度】** 逾期未评教的，教务处可另行通知补评；是否与选课、成绩查询等业务挂钩由学校规定。

3.5 **系统现状**：**未评教不影响**学生查询成绩或选课——本系统中评教与成绩、选课相互独立。**⚙**

## 4. 结果的查看与使用

4.1 教师可查看**本人所授课程**收到的评价内容、评价时间，以及本人在系统中的**平均评分**。**⚙**

4.2 **匿名**：教师**看不到评价是谁提交的**——教师侧接口与 AI 助手工具返回的数据里
**不含提交人学号与姓名**（界面显示为"匿名"）。**⚙**（2026-09-22 按作者确认实现）

4.3 匿名由服务端保证：所有面向教师的读取都经过同一处匿名化处理
（`EvaluationService.pageForTeacher` / `listForTeacher`），**不是靠前端不显示**。**⚙**

4.4 **【制度】** 评价结果主要用于教学改进与教师教学考核参考，不作为对学生成绩的评判依据。

4.5 **【制度】** 任何人不得因学生如实评教而对学生进行打击报复；评价数据的使用应遵守学校数据管理规定。

## 5. 数据管理

5.1 学生**只能查看本人提交的评价**；不能查看他人评价内容。**⚙**

5.2 教师**只能查看本人收到的评价**；不能查看其他教师的评价。**⚙**

5.3 管理员可查看全部评价记录，用于统计与监督。**⚙**

## 6. 附则

6.1 本规则由教务处负责解释。

6.2 与系统行为不一致时，以系统实际行为为准，并及时修订本文件。

### 与系统实现的关系（供审计）

| 条款 | 系统是否自动校验 | 依据 |
|---|---|---|
| 1.2 只能评价本人已选课程 | ⚙ 是 | `EvaluationServiceImpl.add` → `CourseSelectionMapper.select(courseId, studentId)`；未选则拒绝 |
| 1.3 评价对象由课程决定 | ⚙ 是 | `EvaluationServiceImpl.add` 用 `course.teacherId` 覆盖传入值（不一致时记日志） |
| 2.1 5 星制 1~5 | ⚙ 是（助手路径） | `evaluate_teacher` 工具 Schema：`score` 为 `integer`、`minimum 1`、`maximum 5`；界面为 5 星控件（`el-rate :max="5"`） |
| 2.3 对应课程与教师 | ⚙ 是 | `teacher_evaluation(course_id, teacher_id, student_id, score, content)` |
| 3.1 一课一次 | ⚙ 是 | 唯一约束 `uk_eval_course_student (course_id, student_id)`；服务层先给出可读原因（不再 500） |
| 3.2 不可修改 | ⚙ 是 | 只有新增与查询接口，无更新/删除接口 |
| 3.3/5.1 本人评价可查 | ⚙ 是 | `check_evaluation`、`get_my_evaluations` |
| 4.1/5.2 教师看本人评价与均分 | ⚙ 是 | `EvaluationService.pageForTeacher/listForTeacher`（按登录教师过滤）、`avgScoreByTeacherId` |
| 4.2/4.3 **匿名**（教师看不到提交人） | ⚙ 是 | 匿名化在 `EvaluationServiceImpl.stripStudentIdentity` 单点完成；教师侧 REST 与 AI 工具都只走 `pageForTeacher/listForTeacher`；前端该列显示"匿名" |
| 3.5 未评教不影响业务 | ⚙ 是 | 成绩查询与选课均不校验评教状态 |
| 2.1 评分范围强校验（界面路径） | ❌ 未实现 | 数据库 `score int` 无范围约束，REST 接口无 `@Min/@Max`（仅助手路径有 Schema 校验） |
| 3.4 逾期补评 | ❌ 未实现 | 无评教开放时间与状态管理 |
