# 成绩构成与绩点换算办法

> 文档编号：**JW-05**　｜　适用范围：全日制本科生　｜　版本：v1.0（2026-09-20）
> 图例：**⚙** = 系统已自动校验，数值与代码一致；**【制度】** = 管理制度条文，系统当前不自动校验。

---

## 1. 总则

1.1 课程成绩采用**百分制**记载，精确到**小数点后 3 位**。**⚙**（数据库字段 `decimal(6,3)`）

1.2 课程总成绩由**平时成绩**与**考试成绩**按固定权重合成，由**系统计算**，不接受人工直接填写总成绩。**⚙**
> 系统在服务端计算总分，不信任前端或调用方传入的总分，避免"总成绩与分项对不上"。

1.3 成绩数值范围**限定为 0~100**（含端点）；超出范围一律拒绝，**且不会写入任何数据**。**⚙**
> 2026-09-22 按作者确认补上：此前**完全没有范围校验**（数据库只是 `decimal(6,3)`），录 999 分也能存下去。
> 校验放在 `ScoreServiceImpl`，因此**界面录入与 AI 助手录入两条路径都必须过它**；
> AI 工具的参数 Schema 里另加了 `0~100`（但 Schema 只是提示，**服务端才是硬闸门**）。
> 未录入的分项允许为空（表示"尚未录入"），参与计算时按 0 分。

## 2. 总成绩计算

2.1 计算公式：**⚙**

```
总成绩 = 平时成绩 × 0.4 ＋ 考试成绩 × 0.6
```

2.2 结果保留 **3 位小数**，四舍五入。**⚙**

2.3 示例：平时 87.65 分、考试 91.35 分 → 87.65×0.4 + 91.35×0.6 = **89.870** 分。**⚙**

2.4 该公式在系统中**只有一处实现**（`ScoreServiceImpl.calcTotal`），无论从界面录入还是经 AI 助手录入，
结果完全一致。**⚙**
> ⚠️ 曾经 AI 助手侧自行计算总分且只保留 1 位小数，导致同一份成绩走两条路径得到不同结果；已修复并加回归测试。

2.5 分项缺失时按 0 分参与计算；例如未录入考试成绩时，总成绩 = 平时成绩 × 0.4。**⚙**

## 3. 及格判定

3.1 课程**及格线为 60 分**（系统配置项，默认 60）。**⚙**

3.2 判定规则（详见 JW-03 第 2 节）：**⚙**

```
通过 = （总成绩 ≥ 60） 或 （补考成绩 ≥ 60）
```

3.3 **补考通过的成绩一律按 60 分参与一切计算**（成绩单、学分、绩点）。**⚙**

## 4. 单科绩点换算

4.1 换算规则：**⚙**

```
若 成绩 < 60  →  绩点 = 0
否则          →  绩点 = 成绩 ÷ 10 − 5
```

4.2 **等价说法**：绩点 = （成绩的十位数 − 5）+ （成绩去掉十位后的余数 ÷ 10）。
两种写法结果相同；实现上直接用 `成绩 ÷ 10 − 5`，因为更不容易写错。**⚙**

4.3 换算示例（系统已逐条验证）：**⚙**

| 成绩 | 绩点 | 说明 |
|---|---|---|
| 60 | 1.0 | 及格线，恰好 1.0（无特殊分支） |
| 60.1 | 1.01 | |
| 62.3 | 1.23 | |
| 65 | 1.5 | |
| 65.333 | 1.5333 | |
| 75 | 2.5 | |
| 75.76 | 2.576 | 需 2 位小数精度 |
| 85 | 3.5 | |
| 87.365 | 3.7365 | 需 3 位小数精度 |
| 95 | 4.5 | |
| 100 | 5.0 | 上限 |
| 59.9 | 0 | 低于及格线 |
| 0 | 0 | |

4.4 **计算必须使用精确十进制运算**，不得使用浮点数，否则 87.365 会算成 3.7365000000000002。**⚙**

4.5 补考通过的课程按 60 分计算绩点，即**绩点 1.0**。**⚙**

## 5. 平均学分绩点（GPA）

5.1 计算公式：**⚙**

```
GPA = Σ(单科绩点 × 该科学分) ÷ Σ(该科学分)
```

5.2 **只统计已通过的课程**；不及格课程不计入 GPA，也不计入学分。**⚙**

5.3 同一课程代码有多条成绩记录（重修）时，**取绩点最高的一条**计入。**⚙**

5.4 GPA 保留 **4 位小数**。**⚙**（示例：某生累计 GPA 为 3.8834）

5.5 GPA 可按**全部学期（累计）**或**指定学期**统计；学期参数省略时按全部学期累计。**⚙**

5.6 示例（4 门必修课全部通过，共 14.5 学分，平均学分绩点 3.8834）**⚙**

| 课程 | 成绩 | 绩点 | 学分 |
|---|---|---|---|
| Java 程序设计 | 88.000 | 3.800 | 4.0 |
| SpringBoot 开发 | 90.000 | 4.000 | 3.0 |
| 数据结构与算法 | 90.400 | 4.040 | 4.0 |
| 数据库原理 | 87.000 | 3.700 | 3.5 |

## 6. 专业内排名

6.1 排名范围为**同专业、同年级**的学生。**⚙**

6.2 按 **GPA 降序**排名；名次 = **严格高于本人 GPA 的人数 + 1**（GPA 相同者名次相同）。**⚙**

6.3 排名只提供**本人的名次**与专业总人数，**不提供他人的成绩或绩点明细**。学生只能查询本人排名；管理员可查询指定学生。**⚙**

6.4 **【制度】** 排名用于评奖评优、保研等场景时，由教务处导出并加盖公章方为有效。

7.1 本办法由教务处负责解释。
