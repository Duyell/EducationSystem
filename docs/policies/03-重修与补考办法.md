# 重修与补考办法

> 文档编号：**JW-03**　｜　适用范围：全日制本科生　｜　版本：v1.0（2026-09-20）
> 图例：**⚙** = 系统已自动校验，数值与代码一致；**【制度】** = 管理制度条文，系统当前不自动校验。

---

## 1. 总则

1.1 课程考核成绩**及格线为 60 分**。成绩低于 60 分者为不及格。**⚙**（及格线为系统配置项，默认 60）

1.2 不及格课程**不计入已修学分**，也**不计入平均学分绩点**。**⚙**

1.3 不及格课程可通过**补考**或**重修**取得成绩与学分。

## 2. 通过与否的判定

2.1 判定规则如下（总成绩与补考成绩任一达到及格线即为通过）：**⚙**

```
通过 = （总成绩 ≥ 60） 或 （补考成绩 ≥ 60）
计入已修学分 = 通过
计入平均学分绩点 = 通过
```

2.2 判定逻辑在系统中**只有一处实现**（`GpaServiceImpl.isPassed`），成绩录入、学分统计、毕业审核、选课校验全部调用它——
不允许任何模块自行判断"是否通过"。**⚙**

## 3. 补考

3.1 课程总成绩不及格者，可参加**一次补考**。补考由教务处统一安排时间与考场。**【制度】**

3.2 **补考通过的成绩一律按 60 分记载。** **⚙**
即：补考卷面 85 分与补考卷面 60 分，成绩单与绩点计算都按 60 分处理。

3.3 因此补考通过的课程，其**绩点为 1.0**（60 ÷ 10 − 5 = 1.0）。**⚙**

3.4 补考通过后，该课程计为**已通过**，学分计入已修学分。**⚙**

3.5 补考仍不及格者，须**重修**该课程。**【制度】**

3.6 补考**不需要重新选课**，也不占用选课名额。**⚙**（补考安排登记在考试安排中，类型为 `MAKEUP`）

## 4. 重修

4.1 重修须**重新选课**并参加课程学习与考核。重修一般在下一学期（或该课程再次开课时）进行。**【制度】**

4.2 系统**不限制重修次数**，也不因"曾经修读过"而拒绝选课。**⚙**
选课时的"是否已修过"校验以**课程代码**为准，且只拦**已通过**的课程——**挂科的课程可以重修**。**⚙**

4.3 **重修成绩按实际考核成绩记载**（与补考不同，不折算为 60 分）。**⚙**

4.4 同一课程代码有多条成绩记录时（多次重修）：**⚙**
- 平均学分绩点（GPA）：**取绩点最高的一条**计入（避免"重修拉低 GPA"的争议，规则按对学生有利处理）；
- 已修学分：按课程代码归并，**只计一次**学分（不重复累计）；
- 毕业审核：该课程代码只要**有一条已通过记录**，即视为"已通过"。

4.5 **【制度】** 重修课程须按学分缴纳学费；重修成绩单上如实标注"重修"字样。

## 5. 缓考

5.1 **【制度】** 因疾病、突发事故等原因不能按时参加考试的，可于考前申请**缓考**，经批准后随下一轮补考或指定时间参加考试，缓考成绩按实际成绩记载。

5.2 **系统现状**：系统**未实现缓考申请流程**；考试类型只有 `FINAL`（期末）、`MIDTERM`（期中）、`MAKEUP`（补考）三种，其中 `MAKEUP` 用于登记补考。**⚙**

## 6. 成绩记录与更正

6.1 每名学生在**同一门课（同一 `course_id`）上只有一条成绩记录**，由数据库唯一约束保证。**⚙**

6.2 成绩需要更正时，须由任课教师在系统中修改；成绩的录入与修改属于重要变更，须经人工确认后执行，并全程留痕。**⚙**（详见 JW-09）

6.3 补考成绩单独记录（`makeup_score` 字段），不覆盖原始总成绩——原始不及格记录仍可追溯。**⚙**

## 7. 附则

7.1 本办法由教务处负责解释。

7.2 与系统行为不一致时，以系统实际行为为准，并及时修订本文件。

### 与系统实现的关系（供审计）

| 条款 | 系统是否自动校验 | 依据 |
|---|---|---|
| 1.1 及格线 60 | ⚙ 是 | `gpa_rule.pass_score`（默认 60.000） |
| 2.1 通过判定（含补考） | ⚙ 是 | `GpaServiceImpl.isPassed`（**唯一实现**） |
| 3.2 补考通过记 60 | ⚙ 是 | `GpaServiceImpl.effectiveScore`（`return currentPassScore()`） |
| 3.3/3.4 补考后绩点与学分 | ⚙ 是 | `GpaServiceImpl.calcGpa` / `CreditServiceImpl.passedScoresByCourseCode` |
| 4.2 挂科可重修 | ⚙ 是 | `CourseSelectionServiceImpl.selectionBlocker` 第 4 道只拦"已通过" |
| 4.3 重修按实际分数 | ⚙ 是 | `effectiveScore` 仅在"补考通过"时取 60 |
| 4.4 多条记录取最优 | ⚙ 是 | `GpaServiceImpl`（按 `courseCode` 取绩点最高）／`CreditServiceImpl`（按代码归并） |
| 6.1 一课一记录 | ⚙ 是 | 唯一约束 `uk_score_course_student (course_id, student_id)` |
| 6.3 补考成绩不覆盖原成绩 | ⚙ 是 | `score.makeup_score` 独立字段 |
| 3.1 补考一次、5.1 缓考 | ❌ 未实现 | 无补考次数记录、无缓考流程 |
| 4.5 重修学费 | ❌ 未实现 | 无学费模块 |
