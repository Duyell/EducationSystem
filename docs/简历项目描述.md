## 可粘贴版本

**项目名称：教务系统（个人项目 · Java 后端 + LLM Agent）**

**项目概述**：独立开发的教务系统与内嵌智能助手——在真实教务业务（培养计划、绩点、排课、选课、考试）之上，
做出一个**能查真实数据、能办业务、但改数据前必须由用户确认**的 Agent。

- **Agent 能力**：自研 Agent 循环（模型↔工具往复 + SSE 流式输出），33 个业务能力注册为声明式工具
  并按角色隔离（学生 17 / 教师 7 / 管理员 9）；单轮限制 5 轮工具调用、20 次执行，防止失控循环。
- **安全可控（重点）**：四道闸门"角色白名单 → 参数校验 → **危险操作人工确认** → 全量审计"；
  7 个写操作（选课、评教、录改成绩、申请开课/排课、审批）**确认前数据库零变化**，
  确认令牌兼作幂等键；另有输出护栏与频率限制。
- **RAG 制度问答**：11 份制度 / 85 个分块，pgvector + bge-m3，幂等重建索引；因模型会"不检索就作答、
  还编造出处"，改为**服务端路由级强制检索**——Hit@5 **12/12**、MRR **0.944**、忠实度 **9/9**，
  回答带可点击出处并落库。
- **业务与质量**：毕业学分审核、绩点与专业内排名、排课与教室推荐（800 间教室 + 冲突检测）、
  选课六道校验、考试安排、**成绩变更日志**（谁改的、改前改后、界面改还是 AI 改）。
  **326 项后端测试 + 11 套链路断言进 CI**（用确定性假模型替代真实模型），
  真实模型侧另有黄金集 75 项断言、工具选路 10/10。

> 技术栈：Java 21 / Spring Boot 3.5 / MyBatis / MySQL + Redis / PostgreSQL + pgvector ·
> Spring AI + 本地 Ollama（qwen2.5:7b、bge-m3）· Vue 3 + Vite（SSE 流式对话、确认卡片、出处卡片）。

## 别答错的（三条）

- **退课（`drop_course`）标的是 `WRITE`、不弹确认卡片**——答"退课风险低于选课、不占名额"或"要做成一致也很好改"。
- 11 份制度是**自撰的演示语料**（非某校真实规章），别写成"接入校内真实制度库"。
- RAG 与模型质量指标**没进 CI**（要 pgvector + 真实模型，是有意为之）；7B 选路有波动（10/10 与 8/10 都出现过）。
