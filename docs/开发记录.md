### 详细改动

**① 后端角色鉴权（`edu-common/.../interceptor/LoginInterceptor.java` 重写）**
- 新增权限规则表：`/user /teacher /student /clazz /college /major` 仅 admin；`/course` 写操作仅 admin；`/score` 仅 admin+teacher；`/course-selection`、`/evaluate` 仅学生（admin 全程放行）；`/course/my`、`/course/{id}/students` 为 admin+teacher
- 未命中规则的接口维持"仅需登录"（/home、/ai 等）
- 拦截失败返回 403 JSON；预检 OPTIONS 放行
- **数据归属校验（IDOR 修复）**：`ScoreController` 教师查/录/改/删成绩必须指定课程且课程属于自己（`CourseService.isCourseOfTeacher` 新增）；`CourseController` 教师只能看自己课程的选课名单

**② JWT 加固**
- `JwtUtil.java`：密钥改为配置注入 `jwt.secret: ${JWT_SECRET:...}`（生产必须设环境变量），过期时间可配 `jwt.expiration-minutes`
- `LoginInterceptor`：Redis 中的 token 与请求头比对，**重新登录后旧 token 立即失效**
- `LoginServiceImpl`：Redis TTL 从 7 天改为与 JWT 有效期一致（30 分钟），不再残留无用数据

**③ AI 工具归属校验（`TeacherToolRegistrar.java`）**
- `get_course_students`/`enter_score`/`update_score` 均校验课程属于当前教师
- `update_score` 改为先查现有记录、合并字段后重算总分（修复原来只传平时成绩时考试成绩被清零的 bug）
- 学生 `select_course` 工具改为复用新的选课服务（含事务/锁）

**④ 前端 XSS（`views/ai/index.vue`）**
- 新增依赖 `dompurify`，AI 回复经 marked 渲染后 `DOMPurify.sanitize` 再 `v-html`

**⑤ 选课并发控制**
- 新增 `CourseSelectionService`（接口+实现）：选课事务内 `SELECT ... FOR UPDATE` 锁课程行 → 查重 → 容量校验 → 插入；唯一约束兜底重复插入
- `CourseSelectionController` 重构为调用 Service（同时修复了"Controller 直连 Mapper"的架构问题）
- `CourseMapper.selectCourseByIdForUpdate`、`CourseSelectionMapper.select/countByCourseId` 新增

**⑥ 数据库约束（`docs/sql/2026-08-13-security-migration.sql`，需手动执行一次）**
- 清理重复数据 + `course_selection`/`score`/`teacher_evaluation` 三张表加 (course_id, student_id) 唯一约束
- 高频查询列补索引：course_selection.student_id、score.student_id、course.teacher_id、clazz.major_id、major.college_id、teacher_evaluation.teacher_id
- `edujwxt.sql` 已同步更新（新装库自带约束与索引）

**⑦ 前端依赖与类型修复（顺手修复）**
- `package.json` 补声明 element-plus/@element-plus/icons-vue/axios（此前靠父目录提升，单独安装会失败）
- `pnpm-workspace.yaml` 移除 `vue: 'beta'` 覆盖（会导致解析出 vue 3.6.0-beta 预发布版）
- `StudentForm`/`TeacherForm` 的 defineEmits 补 `'close'`（声明与实际使用不符）
- `env.d.ts` 添加 `declare module '*.vue'` 兜底声明（8 个 index.vue 尚缺 lang="ts"，待补全后移除）
- 依赖管理器确认：本项目实际使用 **npm**（package-lock.json），勿再用 pnpm install（会重新生成 pnpm-lock.yaml 且受覆盖影响）
